# Windows Security Event ID Notes

## Authentication Events

### Event ID 4624
Successful Logon

Used for:
- User login monitoring
- Account activity tracking


### Event ID 4625
Failed Logon

Used for:
- Brute force detection
- Password attack investigation


### Event ID 4634
Logoff Event

Used for:
- User session tracking


## Account Management Events

### Event ID 4720
User Account Created

Used for:
- Detect unauthorized account creation


### Event ID 4728
User Added to Security Enabled Global Group

Used for:
- Privilege escalation investigation


## Process Events

### Event ID 4688
Process Creation

Used for:
- Suspicious program execution detection
